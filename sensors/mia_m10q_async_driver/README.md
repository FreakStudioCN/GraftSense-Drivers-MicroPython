## 简介

`mia_m10q_async_driver` 是当前仓库中独立发布的 MicroPython 异步包。设备/功能名称和 API 均来自包内运行时文件；它不是对同步 API 的无依据重命名。源包：`sensors/mia_m10q_driver`。

## 主要功能

- 可解析的公开类：`MicropyGPS`, `MicropyGPSAsync`, `SyncAdapterMixin`。
- 可解析的公开调用入口：100 个（详见 API 矩阵）。
- 异步等级：`cooperative_nonblocking`；依据：等待阶段使用协程让出；底层总线调用仍同步。

## 快速开始

1. 按 `package.json.urls` 将运行时文件复制到设备；不要把 `examples/` 当作运行时依赖。
2. 按上文硬件/运行环境配置总线、GPIO、网络或凭证。
3. 使用包内真实 `code/main.py` 的 import 与构造方式运行。以下是当前文件逐字读取的异步入口；部署时请保留 `try/finally` 并调用对象实际提供的 `deinit()` 或 `aclose()`。

```python
try:
    import uasyncio as asyncio
except ImportError:
    import asyncio

async def main():
    # Python env   : MicroPython v1.23.0
    # -*- coding: utf-8 -*-
    # @Time    : 2026/07/19 00:00
    # @Author  : FreakStudio
    # @File    : main.py
    # @Description : 测试 MIA-M10Q NMEA GPS 驱动类的代码
    # @License : MIT

    # ======================================== 导入相关模块 =========================================

    from machine import Pin, UART
    from mia_m10q import MicropyGPS

    # ======================================== 全局变量 ============================================

    # UART 接收超时时间（毫秒）
    # UART receive timeout in milliseconds
    _UART_TIMEOUT_MS = 5000
    # 循环读取间隔（毫秒）
    # Loop read interval in milliseconds
    _LOOP_INTERVAL_MS = 1000

    # ======================================== 功能函数 ============================================

    # ======================================== 自定义类 ============================================

    # ======================================== 初始化配置 ==========================================

    # UART 硬件引脚定义
    UART_ID = 1
    TX_PIN = 17
    RX_PIN = 16
    BAUDRATE = 9600

    # 上电稳定延时
    await asyncio.sleep(3)
    print("FreakStudio: MIA-M10Q NMEA GPS driver test starting...")

    # 初始化 UART 总线
    uart = UART(UART_ID, baudrate=BAUDRATE, tx=Pin(TX_PIN), rx=Pin(RX_PIN))

    # 创建 GPS 解析器实例
    device = None

    # ========================================  主程序  ===========================================

    try:
        # 创建 NMEA 解析器实例（北京时区 UTC+8）
        # Create NMEA parser instance (UTC+8 Beijing time)
        device = MicropyGPS(local_offset=8)

        print("Waiting for NMEA data from MIA-M10Q...")

        # 启动时刻（用于超时判断）
        gps_start_time = time.ticks_ms()

        while True:
            # 检查 UART 缓冲区是否有可用数据
            # Check if UART buffer has available data
            if uart.any():
                data = uart.read()
                if data:
                    for byte in data:
                        # 逐字符输入 GPS 解析器
                        # Feed characters to GPS parser one at a time
                        result = device.update(chr(byte))
                        if result is not None:
                            print("Parsed sentence: %s" % result)
                    # 数据接收后重置超时计时
                    # Reset timeout timer on data receipt
                    gps_start_time = time.ticks_ms()

            # 输出当前 GPS 信息
            # Output current GPS information
            print(
                "Lat: %s  Lon: %s  Speed: %s  Satellites: %d"
                % (device.latitude_string(), device.longitude_string(), device.speed_string("kph"), device.satellites_in_use)
            )

            # UART 超时检查
            # UART timeout check
            if time.ticks_diff(time.ticks_ms(), gps_start_time) > _UART_TIMEOUT_MS:
                if not device.valid:
                    print("Warning: No valid NMEA data received within %d ms" % _UART_TIMEOUT_MS)

            await asyncio.sleep_ms(_LOOP_INTERVAL_MS)

    except KeyboardInterrupt:
        print("Test stopped by user")

    except Exception as e:
        print("MIA-M10Q test error:", e)

    finally:
        if device is not None:
            device.deinit()
            print("GPS parser deinitialized")
        device = None

if __name__ == '__main__':
    asyncio.run(main())
```

## 超时、取消、并发与残余阻塞

任何 `await` 不会自动使底层 I2C/SPI/UART/Pin 操作变为非阻塞。取消时应停止后台任务并在 `finally` 释放资源；没有实现超时参数的 API 不应被假定具有超时。协议命令、帧界限、ACK、静默间隔及错误含义只以当前实现和源示例可证明的内容为准。



## UART Concurrency Contract

Model: caller-owned
Reader owner: 调用方协程；不得让多个协程同时读取同一 UART。
Frame and unsolicited-data policy: 仅按当前运行时已有帧解析规则处理；未定义的非请求数据不得静默丢弃。
