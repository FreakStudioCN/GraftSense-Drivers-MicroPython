## 简介

`vl53l5cx_async_driver` 是当前仓库中独立发布的 MicroPython 异步包。设备/功能名称和 API 均来自包内运行时文件；它不是对同步 API 的无依据重命名。源包：`sensors/vl53l5cx_driver`。

## 主要功能

- 可解析的公开类：`ConfigDataBytes`, `ConfigDataFile`, `Results`, `VL53L5CX`, `VL53L5CXCP`, `VL53L5CXMP`, `VL53L5CXMPAsync`。
- 可解析的公开调用入口：65 个（详见 API 矩阵）。
- 异步等级：`cooperative_nonblocking`；依据：等待阶段使用协程让出；底层总线调用仍同步。

## 快速开始

1. 按 `package.json.urls` 将运行时文件复制到设备；不要把 `examples/` 当作运行时依赖。
2. 按上文硬件/运行环境配置总线、GPIO、网络或凭证。
3. 使用包内真实 `code/main.py` 的 import 与构造方式运行。以下是当前文件逐字读取的异步入口；部署时请保留 `try/finally` 并调用对象实际提供的 `deinit()` 或 `aclose()`。

```python
import uasyncio as asyncio
from machine import I2C, Pin
from os import stat
from vl53l5cx import DATA_DISTANCE_MM, DATA_TARGET_STATUS
from vl53l5cx import RESOLUTION_4X4, STATUS_VALID, STATUS_VALID_LARGE_PULSE
from vl53l5cx_async import VL53L5CXMPAsync as VL53L5CXMP

def print_distance_grid(distance, status, grid_size):
    for index, value in enumerate(distance):
        print("{:4}".format(value) if status[index] in (STATUS_VALID, STATUS_VALID_LARGE_PULSE) else "xxxx", end=" " if (index + 1) % grid_size else "\n")

async def main():
    await asyncio.sleep(3)
    stat("vl53l5cx/vl_fw_config.bin")
    i2c_bus = I2C(0, scl=Pin(5), sda=Pin(4), freq=1_000_000)
    if 0x29 not in i2c_bus.scan(): raise RuntimeError("VL53L5CX not found on I2C bus")
    tof = VL53L5CXMP(i2c_bus, addr=0x29, lpn=Pin(6, Pin.OUT, value=1))
    try:
        await tof.reset_async()
        if not await tof.is_alive_async(): raise RuntimeError("VL53L5CX not detected")
        await tof.init_async()
        tof.resolution = RESOLUTION_4X4
        tof.ranging_freq = 2
        await tof.start_ranging_async({DATA_DISTANCE_MM, DATA_TARGET_STATUS})
        while True:
            if await tof.check_data_ready_async():
                results = await tof.get_ranging_data_async(timeout_ms=1000, poll_ms=50)
            else:
                results = await tof.get_ranging_data_async(timeout_ms=1000, poll_ms=50)
            print_distance_grid(results.distance_mm, results.target_status, 4)
    finally:
        await tof.deinit_async()

asyncio.run(main())
```

## 超时、取消、并发与残余阻塞

任何 `await` 不会自动使底层 I2C/SPI/UART/Pin 操作变为非阻塞。取消时应停止后台任务并在 `finally` 释放资源；没有实现超时参数的 API 不应被假定具有超时。协议命令、帧界限、ACK、静默间隔及错误含义只以当前实现和源示例可证明的内容为准。
