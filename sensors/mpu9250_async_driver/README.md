## 简介

`mpu9250_async_driver` 是当前仓库中独立发布的 MicroPython 异步包。设备/功能名称和 API 均来自包内运行时文件；它不是对同步 API 的无依据重命名。源包：`sensors/mpu9250_driver`。

## 主要功能

- 可解析的公开类：`AK8963`, `AK8963Async`, `MPU6500`, `MPU9250`, `SyncAdapterMixin`。
- 可解析的公开调用入口：50 个（详见 API 矩阵）。
- 异步等级：`cooperative_nonblocking`；依据：等待阶段使用协程让出；底层总线调用仍同步。

## 快速开始

组合器件使用 `await MPU9250Async.create_async(i2c)`，或构造后 `await sensor.start_async()`。独立 `MPU6500Async`、`AK8963Async` 构造现在不执行总线操作，必须先 `await sensor.initialize_async()`，也可使用各自的 `create_async(...)`。保留来源复位、灵敏度、磁力计校准和单位换算；取消或失败时恢复休眠/掉电状态。外部总线由调用方管理。

以下与 `code/main.py` 一致：

```python
"""MPU9250 asynchronous nine-axis IMU demonstration."""
try:
    import uasyncio as asyncio
except ImportError:
    import asyncio

from machine import I2C, Pin
from ak8963_async import MPU9250Async

# ======================================== 全局变量 ============================================
I2C_ID = 0
I2C_SCL_PIN = 5
I2C_SDA_PIN = 4
I2C_FREQ = 400000
MPU9250_ADDR = 0x68
EXPECTED_WHOAMI = 0x71
PRINT_INTERVAL_MS = 2000

# ======================================== 功能函数 ============================================
async def print_nine_axis(sensor):
    ax, ay, az = await sensor.acceleration_async()
    gx, gy, gz = await sensor.gyro_async()
    mx, my, mz = await sensor.magnetic_async()
    temperature = await sensor.temperature_async()
    print('Accel: %.2f %.2f %.2f | Gyro: %.3f %.3f %.3f | Magnet: %.1f %.1f %.1f | Temp: %.1f C' % (ax, ay, az, gx, gy, gz, mx, my, mz, temperature))

# ======================================== 自定义类 ============================================
# ======================================== 初始化配置 ===========================================
# ======================================== 主程序 ================================================
async def main():
    await asyncio.sleep_ms(3000)
    sensor = None
    try:
        i2c = I2C(I2C_ID, scl=Pin(I2C_SCL_PIN), sda=Pin(I2C_SDA_PIN), freq=I2C_FREQ)
        if MPU9250_ADDR not in i2c.scan():
            raise RuntimeError('MPU9250 not found at 0x%02X' % MPU9250_ADDR)
        sensor = MPU9250Async(i2c)
        await sensor.start_async()
        whoami = await sensor.whoami_async()
        if whoami != EXPECTED_WHOAMI:
            print('Warning: unexpected WHOAMI 0x%02X' % whoami)
        while True:
            await print_nine_axis(sensor)
            await asyncio.sleep_ms(PRINT_INTERVAL_MS)
    except KeyboardInterrupt:
        print('Program interrupted by user')
    finally:
        if sensor is not None:
            await sensor.aclose()
        print('MPU9250 resources released')

asyncio.run(main())
```

## 超时、取消、并发与残余阻塞

任何 `await` 不会自动使底层 I2C/SPI/UART/Pin 操作变为非阻塞。取消时应停止后台任务并在 `finally` 释放资源；没有实现超时参数的 API 不应被假定具有超时。协议命令、帧界限、ACK、静默间隔及错误含义只以当前实现和源示例可证明的内容为准。
