# Changelog

## 1.1.0 — 2026-11-06

- 完成分路PI与160/200ms测速窗口细调，增加带限幅的8%起步I项预置；五组空载正反转/低速复测通过后段基础标准，保留未压至25%的启动峰值记录。

- 增加PC实时四路曲线、微秒耗时装饰器及观测超调/稳态计算；完成100/30/20ms和两种20ms实验优化的实机对比，数据见 docs/PERFORMANCE.md。

- 审阅修复：双输入独立停机、构造失败 IRQ 清理、示例资源释放、整组目标原子校验；补充故障回归与完整提交 hooks。

- 保留原库作者；新增模块和示例署名赵岩松，统一文件头、版本及双语 API 文档。
- 整理六个模块分区、私有方法布局和主程序的显式硬件初始化入口。
- 部分入口新增类型/有限数检查；无效输入更早抛 ValueError，不更改有效输入的 PID/RPM/PWM 计算公式。
- 增加 deinit；控制器停止后注销自有 IRQ，共享 I2C/PCA/注入监测器不由兼容入口释放。
- 编码器查询增加 IRQ 临界区，并预留异常诊断缓冲；回调保留同步 B 相采样和计数顺序。
- 新增七项 PC 回归，补充 README 与规范化报告；已上传 ESP32-C3 并完成单路及四路 PID 实机测试。
- 修正规范检查器对已注册 IRQ 回调的识别，8 个运行源码全部通过规范检查。


- 保留 BusDCMotor 初始化、PWM 原值 1900～4095、0/1 方向、stop_motor、break_motor 的有效参数调用与最终输出语义。
- 新增可选 GPIO 编码器计数、方向、RPM、四路独立 PID、目标与参数接口、电压监测器注入和缓存查询。
- 新增开环/PID/刹车模式隔离，采样全部编码器，仅对 PID 模式写输出。
- 新增 startup_brake 与 pwm_frequency 等可选配置，旧构造器默认全八通道刹车行为仍保留；示例默认不运动。
- 修正 PCA9685 预分频缺少 -1，增加振荡器稳定等待与频率校验。1000 Hz 设定的实际标称频率会与旧版不同。
- 更新安装清单为七个运行库，加入完整调用、迁移说明、独立示例和 13 项 PC 回归。
- 原库调速调试 print 不再保留，类型校验更严格；换向先关闭未使用输入。测试范围见 docs/VALIDATION.md。

原库开环四电机 PWM、停止与刹车接口。此处仅保留原版本标识，不补造发布日期。
